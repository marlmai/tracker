# tracker

Веб-приложение для трекинга ежедневных полезных привычек. Проект выполнен в рамках школьной проектной деятельности. 

Приложение не требует бэкенда, базы данных или процесса авторизации. Вся логика и хранение данных (State) реализованы на стороне клиента.

🔗 **[Live Demo](https://marlmai.github.io/tracker/)** | **[Документация (PDF)](#)** *(ссылка на паспорт проекта, если будет)*

## 🚀 Ключевые особенности (Features)

- **Управление состоянием (State Management):** Отметка привычек сохраняется в `localStorage` и восстанавливается при перезагрузке страницы.
- **Алгоритм подсчета серии (Streak Logic):** Итеративный подсчет последовательных дней выполнения привычки с обработкой пропусков.
- **Визуализация данных:** 
  - Мини-график за 7 дней (рендерится динамически).
  - Столбчатая диаграмма за 7 дней с использованием библиотеки `Chart.js`.
- **Отказоустойчивость:** Обработка ошибок парсинга `localStorage` (защита от поврежденных данных со стороны клиента).
- **Адаптивная верстка:** Корректное отображение от 320px (мобильные) до 4K-разрешений (десктоп) с использованием CSS Grid и Flexbox.

## 🛠 Технологический стек

- **HTML5:** Семантическая разметка (`<header>`, `<main>`, `<section>`, `<article>`).
- **CSS3:** Custom Properties (CSS Variables) для темизации, Flexbox/Grid для лейаута, Media Queries для адаптива.
- **Vanilla JavaScript (ES6+):** 
  - Работа с DOM API (`document.createElement`, `addEventListener`).
  - Модульная структура кода (`render`, `saveData`, `loadData`, `calculateStreak`).
  - Использование `localStorage` API для персистентности данных.
- **Chart.js (v4+):** Подключение через CDN для отрисовки статистики на `<canvas>`.
