# tracker

Веб-приложение для трекинга ежедневных полезных привычек. Проект выполнен в рамках школьной проектной деятельности. 

Вся логика работает на стороне клиента. Никакого бэкенда, баз данных и регистраций — данные сохраняются локально в браузере пользователя.

🔗 **[Live Demo](https://marlmai.github.io/tracker/)**

## ✨ Features

- **Трекинг привычек:** 6 базовых привычек (зарядка, шаги, планка, вода, сон, тренировка).
- **Серия дней (Streak):** Автоматический подсчет количества дней подряд, когда привычка выполнялась.
- **Статистика за неделю:** Визуальная полоска (7 квадратов), показывающая выполнение за последние дни.
- **График за месяц:** Построение столбчатой диаграммы (Chart.js) с общим прогрессом за последние 30 дней.
- **Локальное хранение:** Данные не улетают на сервер, всё хранится в `localStorage`.
- **Адаптивность:** Интерфейс корректно отображается на десктопах, планшетах и смартфонах.

## 🛠 Tech Stack

- **HTML5** — семантическая разметка.
- **CSS3** — кастомные свойства (переменные), Flexbox, CSS Grid, медиа-запросы.
- **Vanilla JavaScript (ES6+)** — вся логика приложения, работа с DOM и LocalStorage.
- **Chart.js** — библиотека для отрисовки графика прогресса (подключена через CDN).
